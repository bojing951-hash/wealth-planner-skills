# v5.5 虚构案例：跨境高收入交易者，个人财富规划（非现实税务建议）

> **此示例的全部数据均为虚构，刻意与真实用户场景采用不同金额。仅演示工作流和数学身份核算。** 未读取银行或券商，也未检索当地法税，未评估任何具体投资产品。

## 输入概况

- 2026-10-12、单一美元现金流模型；假设境内居住、香港收款账户，税收居民身份未知。
- PF 银行收款**口述**：$24,000/月（不是银行流水 VERIFIED）。
- 自有券商的交易利润**口述**：$15,000–$70,000/月，已实现、未实现、可提取状态未知。
- 当前费用：房租 $1,800、日常 $1,250、车贷月供 $900；之前曾提及 $700/月娱乐旅游但本轮未重新确认。
- 未提供：当前自由现金、券商账户**净权益**（扣除保证金债务）、车贷余额与利率、交易经营成本、相关税负、目标与家庭责任。

## 先给用户三个明确判断

1. **$24,000 PF 收款只是用户声称已入账；$15,000–$70,000 股票交易利润不能自动加到银行收入。** 但用户**自己持有**的证券账户净权益（如果被确认）应当算在个人净资产，而不能整户剔除。
2. **当前确定的每月现金义务是 $3,950；如果之前 $700 娱乐仍发生，则为 $4,650。** 这两个数字是不同口径，不是遗漏或重复计算。以12个月作为可调整的现金储备情景：$47,400 / $55,800。当前有无相应储备 **UNKNOWN**。
3. **月度税后可投资资金及整体净资产尚不可判定。** 在不捏造税率的前提下，仍然可以建立资金管理顺序、记录成本和贷款条件、制定多种策略选择，不能用“请咨询税务师”结束全部规划。

## 算术对照

| 项目 | 当前明确支出情景 | 之前旅游仍存在的情景 |
|---|---:|---:|
| 口述 PF 银行月入 | $24,000 | $24,000 |
| 现金义务 | $3,950 | $4,650 |
| **税务与经营成本未定前的简单差额** | **$20,050** | **$19,350** |
| 12个月储备资金目标（启发式） | $47,400 | $55,800 |
| **经核定税后可以投资的金额** | **UNKNOWN** | **UNKNOWN** |
| **券商净值与个人净资产** | **UNKNOWN** | **UNKNOWN** |

不能因为一个月收入超过储备目标，就声称储备已经到位；必须观察真正可用、没有被税务或经营需要占用的现金。

## 资金瀑布（治理顺序，不是自动转账）

`个人到账的已拥有现金 → 经营费用与生活/车贷义务 → 预留经专业验证的税务责任 → 近期开支与流动性储备 → 业务正常运行所需交易资本 → 超出约束的长期持有资产。`

## 两种可供客户选择的条件方案

**策略A：财务安全和核验优先。** 先核对PF实际个人净到账和券商净权益、车贷有效成本，识别潜在税务责任和资本被重复计数的风险；优点是降低信息错误造成的大额决策风险，缺点是短期较少新增市场风险敞口。

**策略B：税务明确后逐步固定留存政策。** 将真正可用的税后现金划分为近期开支、交易经营资本和长期资本，设定按月审查及人为批准的释放条件。优点是让一次性的高交易收益逐渐转化为可独立持有的长期资产；缺点是抽走交易资本可能影响交易收益能力，而长期资产仍承受市场风险。

两种方案暂时都**没有一个看似精确的投资比例**，因为个人净资产、贷款利率、目标和税负尚缺信息。此处不进行任何交易或转账。

## 同时发生的压力事件

假设PF停止付款6或12个月、券商账户同时跌价且不能立即变现、车贷与生活义务继续、税务可能到期；对这位虚构用户而言，6个月当前现金义务至少约 $23,700（若旅游继续 $27,900），12个月约 $47,400 / $55,800，**这只是生活资金需求，不是已经能够生存的证明**。真实可用资金未知，因此“不被迫卖出证券的概率”和可坚持月数都不能计算。

## 30/90/365 天具体执行与衡量

| 时段 | 用户行动（尚未执行） | 可观察的效果证明 |
|---|---|---|
| 30天 | 整理按月汇总的银行PF到账、券商权益/已实现/未实现P&L、车贷本金利率、必要支出及经营成本；与专业人士核对涉及地税务义务 | 一份归属正确的资产负债表，避免内部转账和利润双算 |
| 90天 | 在法税和短期资金条件明确后选择政策A或B，记录交易体系实际留存额度与家庭长期新增资本 | 每月**净新增长期资本**、储备覆盖比例及风险敞口，不把内部转入当新增财富 |
| 365天 | 复盘12个月实际资金结果和历史预测，分别记录外部真实到账、生活成本、税费、交易P&L、投资收益 | 真实拥有金融资产的变化，以及来自行为改变/价格变动/内部转移的不同原因 |

**实际执行、实际财富增加、归因于Skill的价值 = 均未观察到。** 本案例只是演示“每项建议应改变什么决策、带来什么财务机制、怎样证明执行”。
