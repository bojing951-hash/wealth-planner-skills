# Personal Wealth Master Plan — 合成高收入跨境交易案例（v5.6 演示）

> **仅演示 Skill 输出样式，不是真实客户建议。** 日期：2026-10-12；所得类型、税务身份、账户权益、所有权、资产净值及当地最新法律均未核验。以下的月收款也只是场景假设，不代表可持续收入。此文件**不含真实用户个人记录**。规划状态：`CONDITIONAL`。

## 0｜你的下一笔财务决策是什么？

**目标：** 在不影响合理生活和交易经营能力的前提下，逐渐建立与交易体系分离、可供长期生活使用的个人财富。正式目标金额、时间和币种尚未确认。

**目前必须先作的三项决策：**

1. **核对个人真正拥有什么。** PF 平台名义额度不算净资产；每月报告的券商收益 $100k–300k 不是净权益数字；应核对个人券商净权益、已提款/未提款、银行现金和贷款余额，避免重复计算。
2. **将已到账收入与未来义务隔离。** 模拟每月 PF 现金到账 $60k，但税务性质和真正适用税负未核实；不能以 $60k 减消费得到最终可投资资金。先确立条件性保护规则，税务核定与非税务现金规划并行。
3. **建立一份可批准的财富政策。** 定义交易经营资本、生活/债务资金、未来长期生活资本的职责和资金转换触发条件；所有实际操作由用户决定。

**暂不做：** 精确计算税额；承诺某个投资比例；基于未知证券净值推断现有净资产；未经批准执行划款。

## 3｜按用途组织财富（非真实划款）

- **Liquidity / Lifestyle（短期保护）：** 已核实的个人现金中优先 earmark 现金储备及合同支出，数额随实际开支/责任更新。
- **Tax / Operating（义务与经营）：** 将可能的税务责任与交易经营需求作为独立约束；尚未确定具体税率、金额，不假装已留足。
- **Longevity（长期生活）：** 仅从真实属于个人、且经过税务与短期用途核对的资源中研究长年期资金计划。
- **Growth（可承担风险的长期资本）：** 用户选择承担适当风险后再讨论资产类别，不提前开具具体买卖单。
- **Legacy（传承）：** 尚无用户意愿，记为 `NOT_APPLICABLE`，不强制设计信托。

**重要：** 现在各池**实际 earmarked 余额未知**；上面只是作用与分配顺序，不能声称已经创建了 $54k 储备或任何投资账户。

## 4｜个人财富政策（首版草案）

| 规则 | WHEN（触发） | THEN（允许的下一项研究/决策） | BLOCK IF（禁止越过） | 责任人和核验 |
|---|---|---|---|---|
| P-01 账本核对 | 新一笔PF银行入账或券商月结 | 核对真正新增的个人现金/净值及内部转账 | 账户所有权或出金未证实 | 用户；月度到账和券商NAV表 |
| P-02 生活保护 | 准备将现金投入长期风险资产之前 | 核算12个月生活/车贷储备是否真实可用 | 税务、必需开支或其他近期义务未知 | 用户；实际现金/开支月数 |
| P-03 税务与经营 | 新税年、改变交易结构、重大出金 | 由合资格人士核对税务、经营义务及可转移资本 | 无有效法条或收入定性 | 用户+合资格税务人员；书面结论 |
| P-04 长期资本建立 | P-01/02/03完成并经用户同意 | 提出可承受的定期资本转移政策和风险预算 | 自有交易资本不足或短期目标缺口 | 用户；季度实际长期净新增资本 |
| P-05 联合风险 | 交易现金流中断及自有券商资产同时回撤 | 暂停新增不可逆长期资金承诺、重新核对偿付与储备 | 不得自动下单/卖出 | 用户；压力期间现金月数 |

所有规则当前状态是 `PROPOSED`，不是生效的用户授权。下次正常运行应由宿主**询问用户哪一条政策愿意采纳**，确认之后方可记录（存储另需独立授权）。

## 5｜两套可比较的政策

**现状维持：** 不改变交易资金布局，优点是经营灵活，问题是交易净资本与家庭长期资本可能难以分离；暂不能量化真实风险。

**分阶段保全：** 先核对现金及贷款、明确税/经营资金义务；然后由用户批准将真正可承担长期风险的资本定期单独记录/安排。优点是明确用途和审计，代价是交易可用资本减少，且交易盈利可能下降。**没有任何无来源的固定转移比例。**

**压力情景：** 未来连续六个月交易入账为0，同时拥有的股票净权益下跌40%（仅为假设）。若生活支出 $4.5k/月，则六个月现金需要 $27k；若 $5.5k/月，则需要 $33k。由于银行余额未知，不得据此宣称抗压通过。股票亏损金额也必须等待净权益确认。

## 7｜月度/季度/年度治理与复盘

**月度：** 实际到账、家庭开支、净新储蓄（不含银行—券商内部划转）、贷款义务、收入中断风险。

**季度：** 自有券商NAV与交易收入是否高度同向，目标资金覆盖率是否发生变化，政策是否被用户执行；出现偏差时核查原因，**不因为单月行情波动自动修改战略**。

**年度：** 完整资产负债与税务状态、真实家庭目标、未来购买力、政策执行和下一年度选择。

**授权和存储：** 这里没有实际授权交易、转款、税务申报或自动化监控。只有用户额外同意，才可把短摘要保存至私人加密记忆；不向公共 GitHub 写真实财务资料。

### 与普通金融问答的可观察区别

普通问答容易停在“税务风险高、分散投资”。这份 Master Plan 进一步说明：**哪些资产真正属于本人、承担哪些未来责任、钱该按什么条件分配、谁可以决定、何时不能执行，以及如何用实际数据检查制度是否有效。**

此合成案例所体现的是流程设计，不证明这些规则已让真实用户获得更高收益或降低真实损失。
