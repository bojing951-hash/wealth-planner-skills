## 2. 十二状态：原始状态 → v5.5 执行责任和差异

## 3. 关键角色与安全审计

- **宿主是执行者：** 真正调查、文献审查、网络/文件获取、专业判断、运行可选程序、输出报告。
- **Skill是专业规范：** 规定问题分类、三账核对、证据、风险、分层政策、报告顺序与质量门槛。
- **可选代码是会计核验：** `trader_wealth_reconcile.py` 标记用户自述与账单核验的区别，不能判定真实税务身份、银行到账真实性或投资适当性。
- **保留约束：** L0公共资料按宿主权限；L1个人记录需许可；L2写私有记忆需逐次批准；L3自主转账/开户/报税/交易仍被禁止；不传私人资料到Git仓库。
- **PF 与券商区别：** 非本人拥有的 PF 模拟名义资本不计个人资产；本人有受益所有权的券商净权益可以是资产，但需要识别融资、限制和估值。券商内部转账不能重复认定为新增财富。
- **内地/香港/美元：** 香港银行仅是收款地点；税收居民、所得分类、汇兑和可投渠道须独立查证，不自动推定税收结论。

## 4. 相对于 v5.4 的差异与偏离审计

**新增：** 专门的高收入跨境多账户咨询分支、账户所有权核对表、假设性费用与支出区间、同时压力测试、资金层/资金瀑布、可选纯会计核对程序、可选报告质量检查、合成正负样例。

**保留：** v5.3专业咨询，v5.4财务行为—价值归因，v5.2加密记忆与原始 v0.4 总体架构。用户要求复杂投资配置后置，此次未添加资产择时规则。

**未发现结构性偏离，但存在未解决的交付风险：** 数据核对仅是数学而非法律；结构化报告检查容易被模板式文字满足，不能证明实际建议价值；无真实宿主双盲比较；不能将不确定税负预设35–45%写成准确信息；对主账户当前装载的Skill旧版本有误判风险。
