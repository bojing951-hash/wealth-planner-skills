# v5.2 本地记忆跨进程演示（**完全虚构数据**）

**测试方式：** 单个临时私有文件夹，连续启动多个独立的 Python CLI 进程，模拟不同会话访问同一份文件。`--consent-*` 在此仅代表**合成测试模拟批准**，不是对真实用户作过授权；没有使用任何真实用户信息、账户或外部连接。

| 步骤 | CLI 命令 | 观测结果 |
|---|---|---|
| 1 | `status` | `initialized = false`；未经同意不存在记忆 |
| 2 | `init` | 测试批准后创建加密 vault + 独立密钥 |
| 3 | `preview` | 未修改文件，生成 SHA256 变更指纹 |
| 4 | `update` | 指纹+revision 0 配对，写入 revision **1** |
| 5 | 独立进程 `read` | 读到虚构深圳、月收入 **¥20,000**，来源仍为 `user_reported` |
| 6 | 第二次 `preview` / `update` | 新收入 **¥30,000**，revision **2** |
| 7 | `compare --old-revision 1 --new-revision 2` | **1** 个字段变化， `¥20,000 → ¥30,000`，没有金融动作 |
| 8 | `delete` | 删除本地加密库和密钥，再次 `status` 为 false |

**结果：** 两次独立本地命令进程可以使用同一个 OS 用户的相同 vault/key 路径保存并恢复财务状态；模拟批准、变更指纹、版本校验和删除过程工作正常。**这不证明 Codex/Claude Code 的真实宿主授权流程已通过验收，也不证明可以跨云端环境自动共享数据。**
