## 2. 原始十二状态逐项对照（名称和顺序完全不变）

| 状态 | 本版Master Plan工作及Owner（Host执行、Skill指导） | 不可越过的门槛／降级 |
|---|---|---|
| `INTAKE` | HOST 判断用户需要完整规划还是窄问题，采集人生目标与现有决策 | 目标未知只给条件性目标发现规则 |
| `CAPABILITY_CHECK` | HOST 确认真实联网/计算/私有文件权限和已安装版本 | 没有工具则说明，不能冒称来源访问 |
| `FACT_VERIFICATION` | HOST 核对唯一净资产账本、现金、券商NAV和义务 | PF名义额不属于客户，券商NAV不能加PnL再次计算 |
| `JURISDICTION_GATE` | HOST 查材料法律和税年并纳入政策禁止条件 | 法务税务未核实不能形成确定税率/税后可投资额 |
| `HOUSEHOLD_SOLVENCY` | HOST 先核对生活、负债、流动性、税务及经营需求 | 未足额保障就不能假装可长期冒险投资 |
| `GOAL_AND_LIFECYCLE` | HOST 输出目标/负债日期与币种、优先级和资金用途 | 不虚构退休日期、传承义务和家庭目标 |
| `EVIDENCE_RESEARCH` | HOST 按需检索真实理论与机构公开方法 | 理论组织方法≠收益保证；法律不能投票裁决 |
| `MACRO_SCENARIOS` | HOST 仅为有重大影响的长期政策更新慢变量假设 | 单月新闻不触发战术交易 |
| `CANDIDATE_PLANS` | HOST 对比现状与1个以上可行条件替代方案 | 不凭空规定固定百分比或投资收益 |
| `DETERMINISTIC_AND_STOCHASTIC_VALIDATION` | HOST 使用代码或可选脚本检查单笔资产分配与条件情景 | 标准化检查不等于金融建议适合或法律证明 |
| `POLICY_CHECK` | HOST 校验权限、资金占用、法律、流动性、作者与审批 | 未经用户许可没有任何划款/交易/记忆写入 |
| `EXPLAIN_AND_MONITOR` | HOST 交付 Master Plan 与30/90/365责任清单和复核记分卡 | 没有授权定时工具不宣称自动监控 |

**判定：12/12原始状态完全保留；Master Plan 是最终客户交付物，不增设第13个状态。**

## 3. Skill-First 与安全边界

- 宿主负责编排、研究、真实工具调用、最终专业判断与客户沟通；Skill 不自带通用 Agent/搜索/同步/自动投顾。
- 本版**新增的是指导文件、客户模板、JSON数据约定和一个纯标准库的可选静态校验器**。校验脚本不实现投资、报税、开户或回测结果生成。
- L0公开资料按工具权限，L1读取真实财务文件需授权，L2私有记忆写入逐次批准，L3证券交易/转账/自动报税禁止。
- 资产 earmark 是会计标记不是账户转移；未知税负阻断**精确金额**，不阻断其他条件性咨询。临时明文客户文件不能提交到公开项目。
- 经典机构方法仅借鉴已公开的「按目标和期限分层」框架；不宣称与UBS/JPM/CFP背书或获得专业认证。
