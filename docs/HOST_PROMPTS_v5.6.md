# 如何使用 v5.6 Personal Wealth Master Plan

## 首次完整规划（可以复制给已安装 Skill 的 Codex / Claude Code）

> 请确认你实际加载了哪个本地 `personal-finance-planner` 的 `SKILL.md`（绝对路径、version），以 v5.6 `workflows/personal-wealth-master-plan.md` 为工作流程，帮助我建立 **Personal Wealth Master Plan**。先按已知信息提供有用的、标记不确定性的草案，最多只询问5个会改变结论的关键问题。必须交付：①唯一资产负债底账和归属/日期/货币；②人生目标与未来义务；③只分配一次的资金用途分层；④有WHEN/THEN/BLOCK/OWNER/METRIC的个人财富政策；⑤现状与条件替代方案及压力情景；⑥30/90/365行动与人类审批；⑦月季年复盘和证据/待决问题。明确区分现有财富、新储蓄、内部转账及假设的投资收益。不选择具体投资产品、不自动转账/交易/报税、不自动保存私有记忆。涉及税法和宏观数据时，在真实可用的联网工具及权限下核验权威资料，不能核验就标注未核实。

## 有旧计划的复盘

> 使用 `personal-finance-planner` v5.6 的 Master Plan review，先确认实际已加载版本和可用权限。只有在我明确同意访问本地历史记忆时才读取；否则我直接提供旧计划。核对前后资产、收入、债务、生活目标、税务条件变化，区分内部转账、新留存本金、市场损益和未知差异。按我的旧版政策检查实施状态，不将提案当成完成；输出政策保留/更新/废止原因、下一批可执行的30/90/365行动，并在想保存时另外征求我的逐次批准。

**注意：** 安装一个Skill不自动赋予AI银行文件、密钥、网络、开户/买卖或后台定时权限。若需用个人财务数据，先确认宿主提供的安全文件读取及许可。该项目也不产生持牌法律/税务/投资建议。
