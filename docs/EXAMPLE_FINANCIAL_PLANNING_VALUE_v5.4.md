# Wealth Planner v5.4 — 财务规划的行为与财富增量（虚构演示）

**场景为纯假设数据，未读取任何真实财务账户，也不是实际改善证明。** 2026年10月，工作起始20年、年化净投资回报固定5%、未投入资金收益0%、通胀2.5%全部为演算参数，不是未来预测。

## 用户的两种选择

税后收入每月¥20,000；必要消费¥8,000；已独立保护的应急资金¥50,000（假设目标¥48,000）；已有可长期投资资产¥50,000；账户本金归用户所有、无其他流动现金。

**方案A（维持原状）：** 每月非必要消费¥7,000，长期投入¥5,000。

**方案B（仅在不损害生活质量时）：** 非必要消费降低至¥4,000，长期投入提高至¥8,000。这里假设减少的¥3,000确实来自能够调整的消费；如果削减会严重损害健康、社交或家庭生活，方案可能不适合。

两套方案使用相同起始资金、币种、收益和时间，假设每月月末缴入投资组合、投资不提现；模拟的财务资产**不包含**两边同样保留的¥50,000应急储备。

**20年差额 ¥1217413.46**，包含真正额外留存的**¥720000.00本金**，和在固定5%收益假设下的**¥497413.46市场增长**。差额折算为2026年购买力约 **¥742952.06**。如果实际投资零收益，额外财富差额就是720,000元。以上仍只是未发生的假设。

**不能把预测写成“Skill已帮助用户创造121.74万元”：行为尚未执行，收益未发生。**

## 关键反例：多投资≠多积累本金

另一种方案：用户原本已经每月结余¥8,000，却只投¥5,000，将另外¥3,000保留为普通现金。如果只是把后者转去股票/ETF，则两种方案每月**新留存资金相同**，20年新增本金差额为 **¥0.00**。在投资固定5%、现金0%的假设下，投资与现金之间的重新配置会有 **¥497413.46** 的条件性差额，但同时承担了更高市场风险。不能称这部分是“通过节俭新增的财富”，也不能把它当作确定收益。

## 真实行为怎么验证？

**建议行为（尚未发生）：** 30天内梳理可调整消费，经用户确认后进行一个月的可逆试验；每月比较真实工资到账、实际消费、储备余额、投资入账和生活满意度，观察是否至少连续3个月持续保留更多资金。税负、负债与投资收益需额外核验。

**模拟跟踪：** 如果用户以后自报每月消费从¥7,000降到¥4,000、投入从¥5,000增到¥8,000，review 计算器可以记录 *观察到* 的结余变化+¥3,000/月；但这并不能证明投资收益是Skill造成的。真实结果还需核对工资变动、意外消费、市场盈亏、资产估值等。

## 价值评估清单

| 价值 | 期望改善行为 | 可验证的指标 | 目前可宣称 |
|---|---|---|---|
| 现金留存 | 少花真正低价值的¥3,000 | 真实月度净结余 | **尚未发生** |
| 复利 | 被保留资金长期参与投资 | 真实每月流入/后续税费后回报 | **只有条件模拟** |
| 财务安全 | 不动用¥50,000应急储备 | 可支撑必要生活的月数 | **只验证假设输入** |
| 生活质量 | 削减不影响重要生活价值 | 用户报告的消费满意度/压力 | **未知，需用户评估** |
| 投资成本与税务 | 遵守当地规则、控制费用 | 真实费用单、适用税年法律 | **本次未研究** |
| 归因 | 排除收入上涨、汇率与市场变化 | 同期记录和可信反事实 | **因果效果无法确认** |
