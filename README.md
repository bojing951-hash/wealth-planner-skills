# Wealth Planner Skill

**让你的 AI，成为专业的个人财富规划助手。**

一套 Skill，让 Codex、Claude Code 具备系统化的财务规划能力。

从收入管理、税务规划，到长期投资、资产配置、风险控制和财务自由。

结合经济学、金融学、行为科学及法律税务知识，帮助你建立适合自己的长期财富管理体系。

**不只是告诉你如何投资，而是帮你规划如何管理一生的财富。**

---

## 它能为你做什么？

### 01｜全面了解你的财务状况

**你的钱，从哪里来？花在哪里？还剩多少？**

分析收入、支出、资产、负债与现金流，评估财务健康状况。

识别不合理的消费结构、潜在财务风险，以及可以改善的地方。

最终告诉你：你真正拥有多少财富，每个月有多少钱可以用于投资。

### 02｜智能财务与税务规划

**不同收入，不同国家，规划自然不同。**

月薪2万元与月薪20万元，应该怎样管理财富？

生活在深圳、上海、纽约或香港，税务和投资规划有什么区别？

Skill 会指导 AI 研究当地适用的税务制度、社会保障、退休账户和投资规则，分析不同安排对税后财富的影响。

**不仅关注赚多少钱，更关注最终能留下多少钱。**

### 03｜科学的长期投资规划

**不追逐短期热点，让财富长期增长。**

结合现代投资组合理论、价值投资、指数投资及风险管理研究，制定符合个人条件的长期投资策略。

研究股票、债券、黄金、现金等资产的配置方式。

综合考虑投资期限、资产相关性、投资成本、税务和风险。

**目标不是收益最高，而是在可承受的风险下，提高长期财富目标的实现可能性。**

### 04｜10年、20年、30年财富模拟

**你的财务目标，数学上真的可行吗？**

假设你现在拥有10万元，每个月可以投资5000元，未来20年，可能积累多少财富？

如果收入增长、通货膨胀、投资收益或市场环境发生变化，结果又会如何？

Skill 可以指导 AI 执行复利计算、情景模拟和压力测试，帮助你分析：

什么时候可能达到100万、300万、1000万，以及实现财务自由需要哪些条件。

### 05｜动态财富管理

**人生在变化，你的财务规划也应该随之调整。**

收入提高、结婚、买房、移居、退休……

当个人财务条件发生变化时，Skill 可以指导 AI 重新评估原来的规划。

对比新旧方案，分析变化原因，调整资金安排。

**不是一份做完就遗忘的理财计划，而是一套可以反复使用、持续完善的财务管理方法。**

## 为什么它能做到？

**不是让 AI 凭经验给建议。**

**而是给 AI 一套专业的财务决策体系。**

### ① 多学科知识体系

融合经济学、金融学、行为金融学、税务、法律和风险管理等专业知识。

包括格雷厄姆、博格尔、马科维茨、夏普、卡尼曼等研究者的经典理论。

不盲从任何一位大师，而是根据科学证据、适用条件和实际问题选择合理的方法。

### ② 循证决策机制

每项重要建议，都应回答四个问题：

**依据是什么？适用于谁？有什么风险？数学上是否成立？**

区分科学研究、历史经验与主观判断。

当理论之间存在冲突时，分析各自的适用条件，而不是简单地将观点拼凑在一起。

### ③ 自主研究与工具调用

**Skill 提供专业方法，AI 负责执行。**

安装后，Codex 或 Claude Code 可以按照 Skill 的指导，利用自身具备的工具能力：

- 检索金融研究和官方法规。
- 获取宏观经济与市场数据。
- 使用 Python 计算、模拟和验证结果。
- 分析用户提供的财务文件。
- 生成可追溯的财务规划报告。

实际能够调用哪些工具，取决于宿主的功能及用户授权。

**无需重新开发一个独立的 AI Agent。**

### ④ 长期主义与动态纠错

以10～30年的财富积累为核心，而不是预测短期市场涨跌。

重点研究实际利率、长期通胀、资产估值、投资成本和生命周期变化。

定期复核关键假设，在重要条件改变时重新规划。

**长期策略保持纪律，财务决策持续优化。**

## 它是怎样工作的？

只需要告诉 AI：

> 我今年28岁，生活在深圳，月收入2万元，拥有10万元存款，每月消费8000元，希望20年后实现财务自由。
> 请使用 Wealth Planner Skill，为我制定完整的财务与投资规划。

Wealth Planner Skill 将指导 AI 按照六个步骤完成任务：

- **STEP 01｜了解你** — 分析收入、消费、资产、负债、居住地区与财富目标。
- **STEP 02｜研究环境** — 研究适用的税务、法律、投资渠道及长期经济条件。
- **STEP 03｜制定策略** — 综合经济学、金融学与风险管理方法，形成候选方案。
- **STEP 04｜数学验证** — 计算现金流、投资成本、长期复利及风险情景。
- **STEP 05｜输出规划** — 形成包含预算、储蓄、资产配置、财富预测和执行步骤的报告。
- **STEP 06｜持续复核** — 根据新数据重新评估，解释变化并提出调整建议。
