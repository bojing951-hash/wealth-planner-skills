# 可维护的动态财务系统：分层知识、事件驱动、硬约束

## 两个不同节奏

**慢变量（季度/年度）**：生命周期、长周期实际利率、通胀与购买力、人口与退休制度、估值风险区间、资产风险溢价及汇率敞口——用于构建多个10/20/30年资本市场假设。若来源不足，只能列假设，不做“长期回报已确定”的预测。

**必须及时更新的约束（事件驱动）**：税收居民变化、法律生效、报税年度、移居、婚育与遗产事件、收入中断、负债再融资、账户被冻结/平台资格失效、投资产品可售性。不能因为总体是20年规划就低频忽略这些信息。

**日常资金事实（月度）**：资产负债余额、银行已到账收入、真实消费、现金缓冲、税务备付、业务运营开支。不需要每天看市场行情。

## 状态模型

`RAW_FACTS` → `FACT_QUALITY_CHECK` → `JURISDICTION_PREFLIGHT` → `LEGAL_TAX_CLASSIFICATION_CHECK` → `CASHFLOW_DEBT_SAFETY` → `GOAL_BUCKETS` → `EVIDENCE_AND_THEORY_RECONCILIATION` → `LONG_RUN_ASSUMPTIONS` → `SCENARIO_SIMULATION` → `POLICY_RECOMMENDATIONS` → `AUDITABLE_REVIEW`。

法税关键资料缺失时允许生成有限的教育性条件模型，但**不能输出已经核定的税后投资额、保证合法的境外开户路径或唯一最优税务结构**。

## 系统优化目标（多目标、不能变成只有收益率）

在满足硬约束的方案集合中，比较：

- 财富目标达成概率（仅在模型有历史校准和适当样本时报告）；
- 10/20年真实购买力、财富下行分位数与最大现金缺口；
- 收入中断、经济危机、负相关失效、汇率与通胀共振冲击的抗压性；
- 税后总收益、费用及用户维护时间；
- 可执行性、合规性与用户的人生目标/家庭义务。

模型层禁止把专家观点转成一个含糊`master_score`决定一切；需要展示**帕累托权衡与至少一项不同风险/收益备选**。没有足够统计参数时，不能输出带两位小数的“成功概率”。

## 决策与证据审计格式

每次运行产生可追溯记录：`run_id; as_of_date; tax_year; profile_hash; profile_source; sources_with_url_and_last_checked; policy_id_and_version; equation_version; assumptions; candidate_actions; excluded_actions_and_reason; jurisdiction_flags; unresolved_conflicts; simulation_model_id; proposed_review_date; authorization_status`。

正式产品里用户档案和运行日志存放加密私有数据库，不能放在公开Skill仓库。更新条例与证据后保留旧版本，让历史建议可按当时有效规则重演。

## 核心数值原则

- `真实可用投资额 = 已核实可支配收入 - 必要生活费 - 到期债务 - 合理现金储备补充 - 税务备付 - 经营成本 - 短期目标储备`。
- 境外收入税额不明 → `未知`，不是`0`；可给条件性上下限，但不得伪造实际净收入。
- `真实购买力 = 名义资产 ÷ 累计价格指数`（明确币种和通胀路径）；投资名义回报包含税费条件。
- 退休/信托/遗产评估必须考虑资产所在地、居民身份和税后提款，不能只看账户净值。
- 多种资产与多币种场景，要求一致的币种换算日、假设及交易税费；无渠道验证不推荐购买。

## 将来扩展（v0.3 尚未实现）

1. 实时法律检索适配器：官方API/页面→条文比对→人工批准→国家包新版本；无API时必须明确来源时效。
2. 真正的双边税收协定解释器：条约版本、税源、税收居民双重认定、抵免算法、申报要求。**高度法律敏感，必须专业审核**。
3. 交易级多币种税务与成本账本：不同所得种类、时点、成本基础、已缴税凭证、预扣及抵免；暂不用假设税率冒充实际税额。
4. 公开指数多因子情景、Monte Carlo、block bootstrap、尾部风险/收益序列及年度重新校准。
5. 真正的保险、养老金、家庭与遗产规划工作流及地区内合法产品适当性。
6. MCP只读账户连接、人工授权写入、分级权限、法规更新监控；Skill本身不具备持续后台运行能力。
