# 中国内地用户的合规核验检查表（非法律或税务意见）

This is a research checklist, **not** an automatically updated legal database. Always check jurisdiction and effective dates before giving advice.

- [ ] 居住及税收居民身份；境外来源收入的所得类型与申报义务。不要因为香港银行账户收款而认定无需在中国内地纳税。
- [ ] 所得发生年度及实际到账凭证；劳动/劳务/经营/其他性质应由适格专业人士核验。
- [ ] PF等平台支付规则、账户所有权和提现不确定性。名义额度、未提现模拟收益不能等于个人净资产。
- [ ] 个人外汇管理的适用情形和可用合规渠道；不要把结售汇便利化额度解读成境外证券自由投资许可。
- [ ] 境内QDII、ETF、基金、期货等工具的实际准入、额度、费用及投资风险。
- [ ] 如果向公众提供具体证券个性化投资咨询或代客交易，应由律师核验最新证券投资咨询业务规定和资质要求。
- [ ] 银行流水、收入、身份、账户资料：最小权限、加密存储、默认不上传公开代码仓库；不得请求用户提交银行卡PIN/网银密码/验证码。

Starter sources (check validity at point of use):

- 国家税务总局: https://www.chinatax.gov.cn/
- 国家外汇管理局: https://www.safe.gov.cn/
- 中国证监会: https://www.csrc.gov.cn/
- 全国人大/国家法律法规数据库: https://flk.npc.gov.cn/

For any current tax rate / law / jurisdiction classification, cite the exact, current official text in the live response rather than this generic checklist.
